# The Design Atlas — 75 Website Design Styles & Landing Page Gallery

An award-winning interactive exhibition and living design museum showcasing **75 individually art-directed website landing pages**, each representing a unique historical, modern, futuristic, or avant-garde visual aesthetic.

Every landing page was engineered as a distinct standalone production website with dedicated typography, color systems, interactive media containers, bespoke visual treatments, and interactive mechanisms.

---

## 🏛️ Exhibition Architecture & Categories

### Category 1: Major Website Design Styles (01–08)
- **01. Minimalism** — Clean architectural grid, restrained typography, expansive white space, subtle micro-interactions.
- **02. Maximalism** — Dense collage of textures, layered editorial compositions, explosive typography.
- **03. Brutalism** — Raw monospaced layout, high-contrast borders, utilitarian structure, uncompromising honesty.
- **04. Neo-Brutalism** — High-saturation pop colors, heavy black borders, offset card drop shadows, playful badges.
- **05. Swiss / International Style** — Rigorous mathematical grid, asymmetrical balance, objective photography, Grotesk typography.

- **07. Corporate / Professional** — Polished enterprise SaaS aesthetics, metric callouts, trust badges, enterprise clarity.
- **08. Avant-Garde** — Non-conformist experimental layout, diagonal flows, broken grids, provocative interactive motion.

### Category 2: Modern UI Visual Styles (09–16)
- **09. Glassmorphism** — Multi-layered frosted glass panels, backdrop blur (`backdrop-blur-md`), specular highlights.

- **11. Skeuomorphism** — Realistic physical textures (leather, brushed metal, tactile toggles, dials, and glass lenses).
- **12. Flat Design** — Crisp geometric shapes, solid vibrant colors, clean vector iconography, zero gradients.
- **13. Material Design** — Physical elevation hierarchy, floating action buttons (FAB), paper surfaces, ripple states.
- **14. 3D Design** — Dimensional depth, isometric showcases, floating cards with perspective transforms.
- **15. Claymorphism** — 3D inflatable pillowy elements, inner rim lighting, rounded bubbly aesthetic.
- **16. Gradient Design** — Mesh gradients, chromatic aura shifts, radiant neon color bleeds.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or [Bun](https://bun.sh) (recommended)

### Installation
```bash
git clone https://github.com/kari-chiru-naga-hasan22/the-design-atlas-75-styles.git
cd the-design-atlas-75-styles
bun install
```

### Run Locally
```bash
bun run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production
```bash
bun run build
bun run preview
```

## 🛠️ Tech Stack & Implementation Details

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 with custom utility architectures
- **Media Engine**: Custom `ImageBox`, `ImageGallery`, and `InfiniteImageMarquee` with aspect-ratio preservation, lazy loading, and error fallbacks
- **Navigation**: Dual-routing engine supporting both Hash routing (`#/styles/:id` and `#/styles/:num`) and HTML5 History
- **HUD System**: Persistent floating navigation controller (`AtlasHud`) with quick search, category filtering, and direct specimen jumping
- **Icons**: Lucide Icons
